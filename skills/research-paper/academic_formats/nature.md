# Nature Style Guide

Concise venue-specific style notes. Read together with
`templates/nature-paper.md`.

## Front matter

- **Title:** ≤ 15 words; declarative; no unnecessary acronyms.
- **Authors:** Initials before family ("J. A. Smith"). Affiliations as
  superscripts.
- **Abstract:** 150–200 words. Implicit structure (context → gap →
  approach → key result → implication). NO citations in the abstract.

## Section structure

- **Main text** has NO "Introduction" header. Open with a context paragraph.
- Headers used: **Results**, **Discussion**, **Methods** (separate
  formatting style for Methods).
- Subheadings under **Results** are short (≤ 8 words), declarative
  ("LLMs scale predictably until 33 B parameters").

## Citations

- **Nature numeric superscript** in text: "earlier work¹⁻³,⁷".
- References in **order of appearance**.
- For Letters: ≤ 30 references in main text. For Articles: ≤ 50.
- Author list in references uses initials before family; `&` for last
  author; bold volume; year at end in parens.

## Equations

- Display equations are numbered (1) right-aligned.
- Inline preferred when possible to save word count.

## Figures and tables

- Figures: caption begins "**Fig. N |** <short title>." (vertical bar
  after the number).
- Caption then describes panels (a, b, c) and any statistics.
- Subpanel captions are part of the figure caption, not separate.
- Numbers in figures use SI prefixes (12 ms, 5 GB).
- Tables: caption above, "Table N | <short title>".
- "Extended Data" figures and tables are in-line in the paper, separately
  numbered (Extended Data Fig. 1).
- "Supplementary Information" is a separate file (Supp Fig 1, Supp Table 1).

## Methods

- Methods is a separate section after Discussion, with its own subheadings.
- More detailed than Results (the Results discusses outcomes; Methods
  describes how).
- Include statistical analysis subsection.

## Author contributions (CRediT)

Mandatory. Use CRediT taxonomy: Conceptualization, Data curation, Formal
analysis, Funding acquisition, Investigation, Methodology, Project
administration, Resources, Software, Supervision, Validation,
Visualization, Writing – original draft, Writing – review & editing.

Example:
> "A.B. conceived and designed the study. C.D. performed the experiments.
> E.F. analysed the data. A.B. and C.D. wrote the manuscript with
> contributions from all authors."

## Data availability

Mandatory. State whether data is in a public repository (with accession),
in supplementary files, or available on request.

## Code availability

Mandatory if the paper used custom code. Provide a repository URL.

## Style quirks

- "Fig." for Figure (not "Figure" in body); "ref. <N>" for references in
  parens (e.g., "as in ref. 3").
- British spellings allowed but be consistent (analyse vs. analyze).
- Spell out "and" in references (not `&`) except between the last two
  authors.

## Length

- Article: ~3,000 words main text.
- Letter: ~1,500 words.
- Brief Communication: ~600 words.
- These are approximate — check the journal's current author guide.

## Submission

- Manuscript should be a single PDF for review.
- Figures embedded for review; separate high-res files at acceptance.
- Cover letter explaining significance to a broad audience.
- Reporting Summary required (a Nature-specific PDF form).
- Suggest reviewers (and exclude any with conflicts of interest).
