# Thesis / Dissertation Chapter Template

varies by institution; default follows Anglo-American norms. The skill should
ask the user about institutional template requirements before generating.

## Skill-specific instructions

1. Always ask the user **upfront** which thesis style their institution uses
   (Anglo-American three-paper / monograph / continental Habilitation). The
   above is the default but institution rules trump it.
2. Use **double numbering** (e.g., 4.3.2 means Chapter 4 → §3 → subsection 2).
3. The **link-forward and link-back** sentences are mandatory — they make the
   chapter feel like part of a thesis, not a standalone paper.
4. Reference style: institution-defined; ask the user.
5. For three-paper thesis styles, each chapter is essentially a self-contained
   paper — use the appropriate paper template (arXiv / IEEE / Harvard) and
   wrap with chapter-introduction and chapter-summary sections.
