# Sample Data Analysis Report

This example shows the output `analyze_data.py` produces for a small
dataset, plus the prose the writer agent might generate from the
`findings.md` stub.

> **Note.** Numbers are illustrative; the underlying data is synthetic.

---

## Input

`data/study1.csv` (n = 240 participants, two conditions).

| Column        | Type        | Notes                                |
| ------------- | ----------- | ------------------------------------ |
| participant_id | integer    | unique per row                       |
| condition      | categorical | A or B                                |
| pre_score     | numeric     | baseline 0–100                        |
| post_score    | numeric     | post-intervention 0–100               |
| age           | integer     | years                                 |
| gender         | categorical | M / F / NB / prefer-not-to-say       |
| time_minutes   | numeric     | engagement time in minutes           |

## Pipeline command

```bash
python scripts/analyze_data.py \
    --input data/study1.csv \
    --outcome post_score \
    --hypotheses paper-spec.md \
    --out ./analysis/ \
    --seed 42
```

## Excerpt: hypothesis-tests.md (after writer agent expands)

**H1:** *Participants in condition B will improve more (post − pre) than
those in condition A.*

- Test: paired comparison of change scores (B vs. A), Welch's t-test.
- Test statistic: t(231.4) = 3.42; p = .0007 (Holm-corrected).
- Effect size: Cohen's d = 0.44, 95 % CI [0.19, 0.69].
- Sample: n_A = 119, n_B = 117 (4 excluded for missing pre).
- **Decision:** H1 supported.
- Interpretation: condition B participants improved on average 4.7
  points (95 % CI 2.1, 7.3) more than condition A participants.

## Excerpt: prose (Findings section, generated by the writer agent)

> ### 6.2 Effect of condition on post-intervention score
>
> Participants in condition B showed greater improvement than those in
> condition A. Mean change scores were 11.2 (SD = 9.4, n = 117) for
> condition B and 6.5 (SD = 8.7, n = 119) for condition A. A Welch's
> t-test on change scores indicated a statistically significant
> difference, t(231.4) = 3.42, p = .0007 (Holm-corrected); the effect
> size was small-to-medium, Cohen's d = 0.44, 95 % CI [0.19, 0.69].
> A bootstrap of the mean difference (n_boot = 2,000) yielded a 95 % CI
> on the mean difference of [2.1, 7.3].
>
> Robustness checks support this result: excluding the four participants
> with missing pre-scores did not change the conclusion (d = 0.43,
> p = .0009), and a non-parametric Mann–Whitney U test on change
> scores produced a consistent result (U = 8,924, p = .0011, rank-
> biserial r = 0.27).
>
> Figure 4 shows the distributions of change scores by condition; the
> overlap is substantial despite the significant mean difference, a
> reminder that small-to-medium effects describe groups, not individuals.

**Figure 4.** Change-score (post − pre) distributions by condition,
n = 236. Points jittered for visibility; thick lines show medians, thin
lines show 25th and 75th percentiles. Despite a significant mean
difference (Cohen's d = 0.44), individual-level overlap is substantial.

## What the writer agent does *not* do

The script produces *numbers* and *figures*. The writer agent produces
*prose interpretation*. The contract is intentional: the numbers are
exact and verifiable; the prose is reviewable.

If the reported numbers in the prose ever drift from the numbers in
`hypothesis-tests.csv`, the **statistical validator** flags the
inconsistency in `validation/statistical-issues.md` and the
orchestrator halts.
