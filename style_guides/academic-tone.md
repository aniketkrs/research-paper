# Academic Tone and Style Guide

## Purpose
Ensure all generated papers maintain appropriate academic register while remaining clear and engaging.

---

## Core Principles

### 1. Authority Without Arrogance

```
GOOD: "The findings demonstrate a significant relationship between X and Y."
BAD:  "We have conclusively proven beyond doubt that X causes Y."

GOOD: "This study contributes to the understanding of X by..."
BAD:  "This groundbreaking study revolutionizes the field of X."

RULE: Let the evidence speak. State findings directly without inflating their significance.
```

### 2. Precision Over Vagueness

```
GOOD: "Response times decreased by 23% (from 450ms to 347ms) after the intervention."
BAD:  "Response times significantly improved after the intervention."

GOOD: "Among the 1,247 respondents, 68.4% reported weekly usage."
BAD:  "A large majority of respondents reported frequent usage."

RULE: Quantify wherever possible. Replace adjectives with data.
```

### 3. Hedging Calibrated to Evidence

```
STRONG evidence (RCT, large N, replicated):
"The results demonstrate that..." / "X causes Y" / "The evidence shows..."

MODERATE evidence (correlational, moderate N):
"The findings suggest that..." / "X is associated with Y" / "The data indicate..."

WEAK evidence (small N, observational, single study):
"This may suggest that..." / "There appears to be..." / "Preliminary evidence points to..."

RULE: Match confidence of language to strength of evidence.
```

### 4. Active Over Passive (With Exceptions)

```
PREFER ACTIVE:
"We analyzed 500 responses" > "500 responses were analyzed"
"The model predicts outcomes" > "Outcomes are predicted by the model"
"Smith (2023) demonstrated" > "It was demonstrated by Smith (2023)"

PASSIVE IS ACCEPTABLE in:
- Methods section: "Participants were randomly assigned to conditions"
- When the actor is obvious or irrelevant: "Data were collected between March and June"
- When emphasis should be on the object: "Three outliers were removed from analysis"

RULE: Default to active. Use passive only when it serves clarity.
```

## Banned Phrases (AI Voice Markers)

These phrases signal AI-generated text. Never use them:

| Banned | Replace With |
|--------|-------------|
| "In recent years" | Specific date or "Since [year]" |
| "In today's rapidly evolving" | [Delete; be specific about what changed] |
| "It is worth noting that" | [Delete; just state it] |
| "It is important to note" | [Delete; just state it] |
| "In the realm of" | "In [field]" |
| "A myriad of" | "numerous" or "many" |
| "Leverage" (verb) | "use" or "apply" or "employ" |
| "Utilize" | "use" |
| "Facilitate" | "enable" or "support" |
| "Paradigm shift" | [Describe what actually changed] |
| "Game-changing" | [Describe the actual impact with data] |
| "Cutting-edge" | "recent" or "state-of-the-art" |
| "Delve into" | "examine" or "investigate" |
| "Landscape" (metaphor) | "field" or "context" or [be specific] |
| "Navigate the complexities" | [Name the specific complexities] |
| "Shed light on" | "clarify" or "reveal" or "explain" |
| "Pave the way" | "enable" or "create conditions for" |
| "Robust" (overused) | "strong" or "reliable" or "comprehensive" |
| "Holistic" | "comprehensive" or "integrated" |
| "Synergy" | [Describe the specific interaction] |
| "Impactful" | "significant" or "influential" [with evidence] |
| "Innovative" | [Describe what's specifically new] |
| "Transformative" | [Describe what actually transforms] |

## Sentence Variety

### Length Variation
```
Target mix:
- Short sentences (5-12 words): 20% — for emphasis, clarity, transitions
- Medium sentences (13-25 words): 60% — workhouse of academic writing
- Long sentences (26-40 words): 20% — for complex ideas with multiple clauses

AVOID: Multiple long sentences in sequence (fatigue)
AVOID: Multiple short sentences in sequence (choppy)
```

### Structure Variation
```
MIX these patterns:
- Subject-verb-object (direct): "The model achieved 94% accuracy."
- Subordinate clause first: "Although previous approaches relied on X, this method uses Y."
- Adverbial opening: "Consequently, the relationship between A and B..."
- Participial opening: "Considering these limitations, the findings suggest..."
- Question (rare, for emphasis): "What explains this discrepancy?"

AVOID: Starting 3+ consecutive sentences with the same word/pattern.
```

## Transitions Between Sections and Ideas

### Between Major Sections
```
Introduction → Literature Review:
"To contextualize these research questions within existing scholarship, 
the following section reviews..."

Literature Review → Methodology:
"Building on the gaps identified in the preceding review, this study employs..."

Methodology → Results:
"Applying the methodology described above, this section presents the findings..."

Results → Discussion:
"These findings raise several important questions regarding..."

Discussion → Conclusion:
"Taken together, these findings and their implications point to..."
```

### Within Sections (Paragraph Transitions)
```
ADDITION: Furthermore, Moreover, Additionally, In addition
CONTRAST: However, Conversely, In contrast, Nevertheless, Despite this
CONSEQUENCE: Therefore, Consequently, As a result, Thus, Accordingly
EXAMPLE: For instance, Specifically, In particular, To illustrate
ELABORATION: Indeed, In fact, More precisely, That is
COMPARISON: Similarly, Likewise, In the same vein, Analogously
TIME/SEQUENCE: Subsequently, Following this, Prior to, Meanwhile
SUMMARY: In summary, Overall, Collectively, Taken together
```

## Numbers and Data in Text

```
RULES:
- Spell out numbers 1-9; use numerals for 10+
- Exception: always use numerals with units (5 kg, 3 ms, 2 participants)
- Exception: always use numerals for statistics (p = .03, r = .45, n = 8)
- Start sentences with spelled-out numbers: "Twelve participants..."
- Use % symbol with numerals: 45% (not "45 percent" or "forty-five percent")
- Consistent decimal places within a comparison
- Thousands separator: 1,234 or 1234 (be consistent)
- Report exact p-values: p = .034, not p < .05 (unless p < .001)
```

## Discipline-Specific Tone Notes

```
STEM papers:
- More passive voice acceptable
- Equations and formal notation expected
- Concise, dense prose
- Results-driven structure

Social Sciences:
- More narrative, interpretive
- Active voice preferred
- Theoretical framing emphasized
- Longer discussion sections

Humanities-adjacent:
- More discursive, exploratory
- First person sometimes acceptable
- Longer paragraphs
- Argument-driven structure

Business/Management:
- Practical implications emphasized
- "Managerial implications" expected
- Balance of rigor and accessibility
- Framework-oriented

Health Sciences:
- CONSORT/STROBE reporting guidelines
- Very structured format
- Clinical significance alongside statistical
- Patient-centered language
```
